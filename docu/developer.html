Developer Documentation

Technical guide for extending Celonis Delivery Forge.

Architecture

  • FastAPI app entry: foundry.api.main:app
  • UI routes and templates via Jinja2
  • SQLModel domain models with timeline and review services

Key route modules

  • /dashboard and topic pages in ui.py
  • API resources under src/foundry/api/routes/
  • Static assets under src/foundry/ui/static/

Local development

  1. Install package in editable mode.
  2. Run uvicorn foundry.api.main:app --reload.
  3. Use Swagger UI for API testing.
  4. Use Dashboard for integrated UI validation.

Packaging

  • Docker image runs app from /app.
  • Windows standalone is built with PyInstaller script.
  • Root docu/ content is bundled and served in-app.
