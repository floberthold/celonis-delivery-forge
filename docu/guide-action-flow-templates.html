Action-Flow Templates Guide (Step-by-Step)

Use this runbook to apply Make-inspired action-flow templates with safe rollout controls.

1) Choose a Starter Template

  1. Open the template catalog in docs at Action-Flow Template Catalog.
  2. Choose one template from alerts, sync, recommendation, or AI triage families.
  3. Confirm risk level and required ownership roles before configuration.

2) Configure Required Inputs

  1. Set client, project, and owner identifiers.
  2. Set trigger fields (schedule, webhook, or subscription).
  3. Set idempotency key and fallback behavior.

3) Validate in Sandbox

  1. Run happy-path payload once and capture output.
  2. Run one expected failure path and confirm configured error handler behavior.
  3. Confirm timeline entries and required evidence artifacts are present.

4) Run Library Validation

  1. From repository root run: python scripts/validate_action_flow_templates.py.
  2. Resolve catalog/spec/playbook mismatches if any are reported.
  3. Do not promote template changes until validator passes.

5) Promote with Governance

  1. Submit reviewer decision for medium/high risk templates.
  2. Include logs, fallback result, and decision in review evidence.
  3. Record reusable pattern notes for future runs.
