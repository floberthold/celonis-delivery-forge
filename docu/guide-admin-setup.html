Admin Setup Guide (Step-by-Step)

Use this runbook to provision a complete environment with all core, account, and integration features enabled.

1) Prepare Environment File

  1. Copy template to runtime config: Copy-Item .env.example .env.
  2. Set a strong JWT secret in FORGE_JWT_SECRET.
  3. Set FORGE_PUBLIC_BASE_URL to the URL users open in browser.

2) Configure Database

  1. For local setup, keep FORGE_DATABASE_URL=sqlite:///./foundry.db.
  2. For Postgres, set FORGE_DATABASE_URL to your server DSN.
  3. Decide fallback policy with FORGE_DATABASE_FALLBACK_TO_LOCAL.

3) Configure SMTP for Account Emails

  1. Set FORGE_SMTP_HOST, FORGE_SMTP_PORT, FORGE_SMTP_USERNAME, and FORGE_SMTP_PASSWORD.
  2. Set sender identity with FORGE_SMTP_FROM_EMAIL.
  3. Set transport flags: FORGE_SMTP_STARTTLS and FORGE_SMTP_USE_SSL.
  4. Restart app after changing SMTP configuration.

4) Configure Integrations

  1. Set FORGE_CELONIS_API_TOKEN for Celonis companion actions.
  2. Set FORGE_GITLAB_BASE_URL and FORGE_GITLAB_API_TOKEN for GitLab flows.
  3. Keep tokens scoped and rotate regularly.

5) Start Application

  1. Run: uvicorn foundry.api.main:app --reload.
  2. Open /health and verify backend + startup mode.
  3. Open Dashboard and confirm UI loads.

6) Functional Smoke Test

  1. Register new account at /register.
  2. Verify activation email is delivered and link opens successfully.
  3. Trigger reset at /forgot-password and validate reset flow.
  4. Sign in, open My Account, and change profile details.
  5. Run a Celonis preflight from Dashboard.
