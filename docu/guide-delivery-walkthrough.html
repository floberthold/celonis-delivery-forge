Delivery Walkthrough (Step-by-Step)

Follow this sequence to execute a complete delivery cycle with governance checks.

1) Onboarding & Access

  1. Sign in via /login.
  2. Verify your account appears under People.
  3. Confirm project has at least two active members.

2) Create Core Entities

  1. Create client in Clients.
  2. Create project in Projects and assign members.
  3. Create asset in Assets.

3) Run Companion Checks

  1. Open Dashboard Celonis section.
  2. Save tenant connection for target client.
  3. Run preflight checks and review status labels.

4) Execute Delivery Work

  1. Use Todos for implementation tasks.
  2. Use Files for artifacts.
  3. Use KPIs for metric definitions and updates.

5) Governance Review

  1. Open Reviews and submit change request.
  2. Ensure reviewer is different from author.
  3. Record outcome and verify timeline entries in Timeline.

6) Closeout

  1. Verify no blocking reviews remain.
  2. Update project status and health indicators.
  3. Capture snapshot/KPI knowledge for reuse where applicable.
