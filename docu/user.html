User Documentation

Guide for project users and reviewers working in Celonis Delivery Forge.

1. Access the workspace

  1. Open Dashboard.
  2. Log in with your local account if prompted.
  3. Pick the topic page you need from the top navigation.

2. Core workflow

  1. Create or select a client and project.
  2. Register assets and assign memberships.
  3. Submit reviews and track decisions.
  4. Use timeline views for governance history.

3. Review governance rules

  • Author and reviewer must be different people.
  • Only assigned project members can submit/review.
  • Approvals and change requests are recorded in timeline entries.

4. Common pages

  • Projects for project lifecycle and memberships
  • Assets for data model and ownership
  • Reviews for request and decision flow
  • Timeline for auditing events
