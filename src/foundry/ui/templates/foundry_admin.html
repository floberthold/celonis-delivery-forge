User management policy

Global admins can manage all users and memberships across all orgs.

  • Account scope: User identity is global. Organization access is membership-based.
  • Global role: Controls platform-level capabilities such as Foundry Admin.
  • Org role: Controls what the user can do inside a specific organization.
  • Safety check: Last owner/admin of an org cannot be removed by accident.
