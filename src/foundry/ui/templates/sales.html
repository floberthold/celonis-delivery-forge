TryCelonis Demo Overview

This page is the sales-facing catalog of TryCelonis partner demos that we want to rebuild in Forge. It explains the source, stores the overview in the database, and links every entry back to its original external source.

Use it to decide which demo should get its own repository, which client or industry branch should be created, and which variant should be deployed into the shared sandbox space for an upcoming customer meeting.

  • One demo overview row per TryCelonis entry.
  • One managed git repository per rebuilt demo app.
  • One client and industry branch per customer-specific variant.
  • One shared sandbox space for on-demand demo deployments.

How This Workflow Fits Delivery

  1. Sync the TryCelonis overview into Forge.
  2. Inspect the source link and summary for the selected demo.
  3. Bootstrap or update the rebuilt demo repository.
  4. Create a dedicated branch for the target client and industry.
  5. Deploy that branch into the shared sandbox space only when the demo is needed.
