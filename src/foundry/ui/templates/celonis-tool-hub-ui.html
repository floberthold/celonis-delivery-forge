About Tool Hub

How to Use

  1. View Tools: Browse all available MCP servers and tools above
  2. Start Tools: Click "Start Tool" to launch enabled tools, or copy the command to run manually
  3. Monitor Status: Green badges indicate enabled tools; Phase numbers show rollout stage
  4. Direct Start: Use PowerShell at repo root: ./START.ps1 -Mode start

Activation Phases

  • Phase 1: Core data generation tools (active)
  • Phase 2: Analytics and ML tools
  • Phase 3: Process mining and transformation tools
  • Phase 4: Backup and utility tools

Tool Status

  • Startable - Tool has been discovered and can be launched
  • Not Startable - Tool not found or prerequisites missing
  • ● - Tool is enabled in the registry
  • ○ - Tool is disabled (awaiting phase activation)

Command Reference

Command Description
./START.ps1 Start all enabled tools (default mode)
./START.ps1 -Mode dry-run Discover and validate tools without starting
./START.ps1 -Mode status Show currently running tool processes
./START.ps1 -Mode stop Stop all running tools
