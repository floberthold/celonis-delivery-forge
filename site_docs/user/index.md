## Daily Route Map

- `/dashboard`: primary action hub and integration actions.
- `/clients-ui`: client registry and details.
- `/projects-ui`: project registry and status.
- `/assets-ui`: delivery artifacts.
- `/reviews-ui`: governed review flow.
- `/todos-ui`: task execution.
- `/files-ui`: artifacts and links.
- `/timeline-ui`: audit and chronology.
- `/orchestration-ui`: quest and assignment coordination.
- `/kpis-ui`: KPI definition and updates.
- `/kpi-book-ui/{client_id}`: client KPI collection view.
